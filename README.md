# Leaffliction

## Description

Leaffliction is a 42 project that simulates the spread of an affliction on procedurally generated leaves using recursive graphics and basic computer vision techniques.

---

## Instructions

Install and activate virtual environment:

```bash
make
```
```bash
source ~/goinfre/leaf_venv/bin/activate
```

Analysis of the Data Set:

```bash
python src/distribution.py Apple
```

Data augmentation:

```bash
python src/augmentation.py
```
